# Contributing to Event-Sourced Agent OS

Thank you for your interest in contributing!

## Development Setup

1. Clone the repo
2. `npm install`
3. `cp .env.example .env` and add your keys
4. `npm run dev`

## Testing

Run the deterministic test harness:
```bash
npm test
```

## Code Style
- TypeScript strict mode
- Prefer composition over inheritance
- Keep skills focused and single-responsibility

## Pull Requests
- Keep PRs focused
- Update documentation when changing behavior
- Add or update tests for new skills/features
